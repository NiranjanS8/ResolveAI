# Account Access and Profile Changes

## Changing the email address on an account

To change the registered email, sign in and go to Settings → Profile → Email. We
send a confirmation link to both the old and the new address. The change takes
effect only after the link sent to the old address is confirmed; this prevents
account takeover if a session is left open.

Support cannot change a registered email directly. If the customer no longer has
access to the old mailbox, treat it as a lost-account case (see below).

## Lost access to the registered email

If the customer cannot receive mail at the registered address, identity must be
verified before the email is changed. Verification requires two of the following:

- A recent order number
- The last four digits of the payment method on file
- The billing address on the account

If two checks cannot be satisfied, the request is escalated to the account
security team. Never change the registered email on a single weak signal.

## Updating the phone number

Phone numbers can be updated from Settings → Profile → Phone. We send a one-time
code to the new number to confirm it. The old number stops receiving alerts
immediately after the change.

## Deleting an account

Customers can request deletion from Settings → Account → Delete account. Deletion
is permanent and removes order history after the statutory retention period.
Active subscriptions and pending refunds must be settled first; if either exists,
support explains this and does not proceed with deletion until they are resolved.

After a deletion request we hold the account in a 30-day grace period during which
the customer can cancel the deletion by signing in. After 30 days the data is
removed.

## Merging duplicate accounts

Duplicate accounts created with different emails cannot be merged automatically.
Support should confirm which account holds the order history and ask the customer
to use that account going forward. Escalate to the account team if paid
subscriptions exist on both accounts, so billing can be reconciled.
